# ADR 0004: EPUB rendering decisions

- Status: Accepted
- Date: 2026-11-20
- Source: code comments removed in the comment cleanup

## Bookmark lookup tolerates a torn-down rendition

**Context.** currentLocation() can throw while navigation settles or after the reader unmounts.

**Decision.** Catch the error and fall back to null when reading the current CFI.

**Consequences.** Bookmark state reads as "no current location" during teardown instead of crashing.

**Code.** `app/hooks/use-book-reader-actions.ts#getCurrentCfi`

## EPUB relocation prefers the adapter location and falls back to a spine-only CFI

**Context.** The adapter stamps location on the same relocation event but may not have done so yet.

**Decision.** Use rendition.location.start.cfi, otherwise build epubcfi(/6/<(spineIndex+1)*2>!/4).

**Consequences.** Page UI updates even before the adapter has a precise location.

**Code.** `app/hooks/use-epub-lifecycle.ts#handleRelocation`

## Publisher page numbers win over sampled locations

**Context.** Some EPUBs ship a nav/NCX page-list with real print page numbers.

**Decision.** Use resolvePublisherPage when a page-list exists; otherwise use character-sampled locations (an epub.js-style heuristic), which are only generated when there is no page-list.

**Consequences.** Page numbers match the print edition when available; heuristic location generation is skipped for those books.

**Code.** `app/hooks/use-epub-lifecycle.ts#handleRelocation`

## EPUB chapter indexes count only leaf TOC entries

**Context.** Chapter uploads (extractBookChapters) number chapters by leaf TOC entries. "Part" containers that hold chapters are not chapters themselves.

**Decision.** logicalChapterIndex skips Part containers and counts only leaf entries, matching extractBookChapters.

**Consequences.** The chapter index the reader reports matches the uploaded chapter index; counting parts would report chapters ahead.

**Code.** `app/hooks/use-epub-lifecycle.ts#logicalChapterIndex`

## EPUB page index comes from per-section position samples

**Context.** A whole-book percentage puts the first chapter around 40% when front matter is long or uneven.

**Decision.** pageIndexFromPositions maps href plus localProgression onto the sampled positions list.

**Consequences.** First chapter starts at the right page (2 in the fixture), and page turns inside a section move the page number.

**Code.** `app/hooks/use-epub-lifecycle.ts#pageIndexFromPositions`

## EPUB page insets are layout geometry, separate from the margin preference

**Context.** The user typography margin setting and the page chrome insets were being conflated. On mobile single-page mode the iframe is full width.

**Decision.** Page chrome insets are not part of the typography margin. On mobile single-page they are applied inside the full-width iframe; on desktop and in scroll mode they stay on the host surface.

**Consequences.** Margins behave the same across layouts; changing inset code means checking both mobile and desktop paths.

**Code.** `app/hooks/use-epub-lifecycle.ts#preferenceCss`

## Position restore falls back to CFI display when layout display fails

**Context.** Displaying by stored layout can fail if resize settling has not finished.

**Decision.** Catch the error and fall through to displayCfiWithFallback.

**Consequences.** Restore still lands on the CFI even if layout geometry is not ready.

**Code.** `app/hooks/use-epub-lifecycle.ts#displayCfiWithFallback`

## Chapter-clipped progress is not stored as a spine percentage

**Context.** When the navigator shows a clipped content range (review mode), localProgression is relative to the clip, not the full spine item.

**Decision.** Drop localProgression when currentContentRange is set; exact return-page geometry lives only in the review's opaque locator.

**Consequences.** Saved positions are never polluted by clipped percentages.

**Code.** `app/hooks/use-epub-lifecycle.ts#saveRelocation`

## Do not save positions while restoring the reading position

**Context.** Mounting the spine emits a section-start CFI before the stored position is displayed.

**Decision.** While suppressPositionSaveRef is set, skip in-memory and IndexedDB position updates, and keep latestCfiRef on the known-good stored position.

**Consequences.** Refreshing reopens at the saved spot, not the chapter start.

**Code.** `app/hooks/use-epub-lifecycle.ts#suppressPositionSaveRef`

## Review selectors are read as plain values in the EPUB lifecycle

**Context.** The third-party navigator lifecycle and effect dependency lists need plain values, not signals.

**Decision.** Read reviewRequirement and reviewPreferences with useValue().

**Consequences.** Effects re-run when review state changes.

**Code.** `app/hooks/use-epub-lifecycle.ts#useEpubLifecycle`

## EPUB review effect keeps its own dispatch reference

**Context.** Parent cleanup can dispose the Store before this child effect cleans up, and the disposed store.dispatch getter then fails.

**Decision.** Capture store.dispatch into a local when the effect runs and use it in cleanup to send closeReviewBook.

**Consequences.** Cleanup always dispatches closeReviewBook; it must not read store.dispatch lazily.

**Code.** `app/hooks/use-epub-lifecycle.ts#useEpubLifecycle`

## Only the active private EPUB reader owns a review context

**Context.** Public and PDF readers also use the EPUB lifecycle but must not register review state.

**Decision.** reviewContext is opt-in and set only by the active private EPUB reader.

**Consequences.** Review sagas track one reader per book.

**Code.** `app/hooks/use-epub-lifecycle.ts#UseEpubLifecycleConfig.reviewContext`

## EPUB selection popover dismiss listener attaches to current and future iframes

**Context.** registerSelectionHandler runs after the first content has loaded, and page turns load new iframe documents.

**Decision.** Attach the mousedown dismiss listener to existing getContents() documents and register a content hook for future documents.

**Consequences.** The popover closes on any click without a selection, on every page.

**Code.** `app/hooks/use-highlights.ts#registerSelectionHandler`

## Progressive fuzzy search for AI-generated quotes

**Context.** AI models quote book text with smart quotes, dashes, ellipsis chars and whitespace that may not match the EPUB source (or vice versa).

**Decision.** fuzzySearchBookForCfi tries the exact query, then normalizeSearchText (straight quotes, -- for em dash, - for en dash, ... for ellipsis, regular spaces for NBSP, zero-width chars stripped, whitespace collapsed), then normalized prefixes of 60 and 30 characters. Per-section search failures are non-fatal and skipped.

**Consequences.** Prefix fallbacks can match a different passage that shares an opening; partial results are returned if some sections fail.

**Code.** `app/lib/epub/epub-search.ts#fuzzySearchBookForCfi`

## Cover extraction failure does not block EPUB import

**Context.** Cover images are often malformed or missing in EPUBs.

**Decision.** Cover extraction errors are caught and ignored during import; the book imports without a cover.

**Consequences.** Books may silently lack covers.

**Code.** `app/lib/epub/epub-service.ts`

## Chapter extraction uses TOC leaf entries and keeps TOC positional indexes

**Context.** Chat and reviews need logical chapters that match what a reader sees, and stored chapter data predates newer fields.

**Decision.** EPUB TOCs often use top-level entries for 'Part' containers, so extraction prefers leaf entries. The legacy chat grouping by spine start is preserved; reviewBoundaries subdivide that text at fragment anchors without renumbering existing chat locations. Chapter index stays the tocStarts position even when empty-text chapters are dropped, because logicalChapterIndex (successor-toc.ts) derives the reader's chapter from the same TOC start list and compacting would report chapters ahead of the reader. Segment separators ('\n\n') are gaps that belong to no spine item. `segments` is absent on chapters extracted before per-spine bookkeeping; `reviewBoundaries` missing means old extraction, empty means incomplete source or unresolved TOC anchors.

**Consequences.** Chapter indexes can be sparse; consumers must handle absent segments/reviewBoundaries from legacy data.

**Code.** `app/lib/epub/epub-text-extract.ts#extractBookChapters`

## Resolve theme colors to rgb and inject them into EPUB iframes

**Context.** App CSS variables use oklch(), which may not be supported in the EPUB iframe. Publisher CSS (e.g. Google Docs exports with color:#000000 on spans) overrides body color. The navigator paints hard-coded theme colors on html, and multi-column pagination can reveal the root beside columns.

**Decision.** resolveThemeColors temporarily toggles the dark class if needed and reads getComputedStyle from a hidden probe element using the variables as real color properties, yielding browser-resolved rgb() strings. getThemeColorCss sets the same background on both html and body (a mismatch shows as later pages having a slightly different dark background) and forces color: inherit on a broad list of text selectors so the body theme color wins.

**Consequences.** Publisher text colors are overridden; theme resolution touches the live document class list briefly.

**Code.** `app/lib/epub/epub-theme-utils.ts#getThemeColorCss`

## Publisher page resolution prefers live pagebreak geometry with spine fallback

**Context.** EPUB page-lists give publisher page numbers; mapping the current view to a page needs either layout or interpolation.

**Decision.** totalPages is the last numeric page, or the entry count when labels are non-numeric. resolvePublisherPage uses live pagebreak geometry only when the document has a real viewport (happy-dom and unloaded iframes report 0x0 and would never mark targets reached); a target is reached unless it is entirely right of or below the viewport (already-passed markers with negative offsets count). Unresolved markers count only at section start to avoid skipping ahead. Without layout, it uses the last entry on an earlier spine then interpolates by local progression among entries on the active spine.

**Consequences.** Page numbers in test/unloaded contexts come from interpolation and can differ from on-screen geometry.

**Code.** `app/lib/epub/publisher-pages.ts#resolvePublisherPage`

## Review checkpoints subdivide legacy chapters at TOC fragment anchors

**Context.** Chapter reviews need finer units than legacy chat chapters, without changing existing chapter text, indexes or segments.

**Decision.** buildReviewChapterBoundaries splits a chapter at TOC fragment anchors using offsets in the same trimmed body.textContent convention as legacy extraction (text and CDATA nodes both count). Text before the first heading is retained in the first unit. Any missing anchor or spine source makes the chapter ineligible (empty list) rather than generating a question about incomplete text. reviewBoundaryContains requires a source-body offset for fragment chapters because a spine index alone is ambiguous.

**Consequences.** Chapters with any unresolved anchor get no reviews.

**Code.** `app/lib/epub/review-chapter-boundaries.ts#buildReviewChapterBoundaries`

## Server EPUB parsing uses a lazily installed happy-dom window

**Context.** EPUB parsing and CFI generation need DOM APIs on the server, and happy-dom Range instances read the window's active document.

**Decision.** parseEpubServerDocument parses spine XHTML and assigns it as the window's active document so happy-dom Range instances operate on it.

**Consequences.** Server EPUB work is not concurrency-safe across documents sharing the window.

**Code.** `app/lib/epub/server-dom.ts#parseEpubServerDocument`

## Successor TOC leaf flattening mirrors epub-text-extract

**Context.** Two code paths flatten the TOC into chapters: flattenTocToLeafEntries (successor-toc.ts) and flattenTocToUsefulEntries (epub-text-extract.ts).

**Decision.** Flatten to leaf entries: 'Part' containers that have nested children are skipped in favor of their leaves, exactly like flattenTocToUsefulEntries.

**Consequences.** Both functions must be changed together or chapter numbering diverges.

**Code.** `app/lib/epub/successor-toc.ts#flattenTocToLeafEntries`

## Logical chapter index must match extractBookChapters indexing

**Context.** The chat prompt resolves chapters by index; the reader computes the current chapter index from the spine position separately from text extraction.

**Decision.** logicalChapterIndex counts only titled leaf TOC entries that resolve to a spine item, deduped by spine start, exactly like extractBookChapters in epub-text-extract.ts.

**Consequences.** Any divergence makes the model report the wrong chapter; both must change together.

**Code.** `app/lib/epub/successor-toc.ts#logicalChapterIndex`

## EPUB search falls back to exact match when case folding changes length

**Context.** Locale case folding can change string length (for example İ becomes i̇), which shifts offsets between the folded and original text.

**Decision.** When folding changes the query length, search uses exact matching instead of case-insensitive matching.

**Consequences.** No misaligned highlight offsets; such queries are case-sensitive.

**Code.** `packages/epub-successor search (spine.find)`

## EPUB search returns range CFIs

**Context.** Search results are drawn as highlight decorations over the matched text, which needs a start and end.

**Decision.** spine find() returns range CFIs (base,start,end), not collapsed points.

**Consequences.** Results can be highlighted directly; consumers must handle range CFIs.

**Code.** `packages/epub-successor search (spine.find)`

## Images stay inside publisher-narrowed containers

**Context.** Publisher margins can narrow the containing block below the column width.

**Decision.** Wide images must stay within both container edges rather than spilling into the column gutter; E2E asserts this.

**Consequences.** Layout CSS must constrain images to their container.

**Code.** `packages/epub-successor/e2e/epub-successor.spec.ts`

## Interactive page turns at the final endpoint go through the host policy

**Context.** Review boundaries are enforced by the host navigation policy.

**Decision.** An interactive page turn at the final endpoint reaches the same host boundary policy as programmatic navigation; E2E covers this for paginated modes.

**Consequences.** No gesture path bypasses review boundaries.

**Code.** `packages/epub-successor/e2e/review-boundaries.spec.ts`

## Some test fixtures are intentionally invalid EPUBs

**Context.** Fixtures must probe security and policy handling.

**Decision.** buildFixtureArchives produces byte-identical archives; traversal, compression-ratio and entry-count fixtures are intentionally EPUBCheck-invalid ZIP/security probes; the scripted fixture omits the "scripted" manifest property; external-reference and meta-refresh fixtures violate the scriptless/offline policy on purpose.

**Consequences.** Do not "fix" these fixtures to pass EPUBCheck.

**Code.** `packages/epub-successor/fixtures/build.ts#buildFixtureArchives`

## Content iframe sandbox allows same-origin and scripts

**Context.** Parent-owned measurement and selection need same-origin; Safari also requires allow-scripts for host-installed callbacks (keyboard, selection, decoration handlers).

**Decision.** CONTENT_IFRAME_SANDBOX is "allow-same-origin allow-scripts"; publication scripts stay blocked by sanitization and CSP script-src 'none'.

**Consequences.** Security relies on sanitizer + CSP, not sandbox alone.

**Code.** `packages/epub-successor/src/content-pipeline/content-pipeline.ts#CONTENT_IFRAME_SANDBOX`

## Content transforms are always followed by sanitization

**Context.** Host transforms mutate section DOM.

**Decision.** ContentTransform output is always sanitized before serialization.

**Consequences.** Transforms cannot introduce unsafe content.

**Code.** `packages/epub-successor/src/content-pipeline/content-pipeline.ts#ContentTransform`

## Context-menu press on a decoration prevents selection start

**Context.** Chrome selects the word on right-click (or ctrl+click).

**Decision.** Decorations preventDefault on mousedown for context-menu presses that hit a decoration.

**Consequences.** Highlight menus open without altering selection.

**Code.** `packages/epub-successor/src/decorations/decorations.ts#handleMouseDown`

## Nav page-list is kept even when TOC comes from NCX

**Context.** The nav document may have an empty TOC that is later filled from NCX.

**Decision.** A non-empty page-list from nav is retained independently of TOC source.

**Consequences.** Page lists are not lost.

**Code.** `packages/epub-successor/src/epub-parser/publication.ts`

## Ephemeral positions are not persistent locators and skip empty sections

**Context.** Readers want page-number-like positions.

**Decision.** generateEphemeralPositions samples every 2,500 characters; one-based positions may change with content and must not be persisted. Zero-text sections are skipped so image-only front/back matter does not inflate the count; numbering starts at the first section with text.

**Consequences.** Positions are display-only.

**Code.** `packages/epub-successor/src/locations/locations.ts#generateEphemeralPositions`

## Adjacent page text never substitutes a previously visited page

**Context.** Unmounted spine neighbours have no layout.

**Decision.** adjacentPageText returns nothing for unmounted neighbours rather than cached text from a previously visited page.

**Consequences.** Consumers must handle missing adjacent text.

**Code.** `packages/epub-successor/src/navigator/adjacent-page-text.ts#adjacentPageText`

## Malformed fragment escapes are treated literally

**Context.** Fragment ids may contain invalid percent escapes.

**Decision.** If decodeURIComponent throws, the raw id is used.

**Consequences.** Lookups do not crash.

**Code.** `packages/epub-successor/src/navigator/content-range.ts`

## Content range hides nodes without removing them

**Context.** CFIs depend on element/text sibling indexes.

**Decision.** applyContentRange hides out-of-range content from layout without removing or reparenting nodes; direct text siblings (unstyleable) have their data blanked and restored later.

**Consequences.** CFIs in the readable interval remain valid.

**Code.** `packages/epub-successor/src/navigator/content-range.ts#applyContentRange`

## Content ranges are DOM intervals with exclusive ends

**Context.** A navigator content range limits a spine item to an interval; fragment endpoints keep the original CFI tree.

**Decision.** NavigatorContentRange is a DOM interval within one spine item; the end belongs to the next unit, including collapsed navigation anchors (rangeContainsRange uses exclusive end).

**Consequences.** Adjacent ranges do not overlap.

**Code.** `packages/epub-successor/src/navigator/content-range.ts#rangeContainsRange`

## Navigation admission is host-owned

**Context.** Review flow needs to block navigation.

**Decision.** NavigatorNavigationPolicy lets the host resolve/allow navigation; the engine owns layout only and never stores review business state.

**Consequences.** Engine stays app-agnostic.

**Code.** `packages/epub-successor/src/navigator/navigation-policy.ts#NavigatorNavigationPolicy`

## Pagination horizontal padding is always zero

**Context.** Horizontal margins are host chrome.

**Decision.** Pagination CSS keeps body horizontal padding at 0; the margins preference does not apply to sides.

**Consequences.** Pages share one origin.

**Code.** `packages/epub-successor/src/navigator/navigator.test.ts`

## First mount is hidden until clipped and positioned

**Context.** A newly mounted frame would paint before layout.

**Decision.** Frames start visibility:hidden, even on first mount.

**Consequences.** No flash of unpositioned content.

**Code.** `packages/epub-successor/src/navigator/navigator.ts`

## Capture actual page before boundary handoff

**Context.** A rapid turn may have snapped a pending animation to its destination.

**Decision.** #boundaryTarget emits a relocation for the settled mount before asking the policy, so the host records the actual return locator.

**Consequences.** Return locators are accurate.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#boundaryTarget`

## Same-section display re-settles in place

**Context.** Remounting the iframe flashes text and rebuilds layout.

**Decision.** display() for the active section reuses the existing mount, bumping operationId to bind it to the new operation for abort checks. Without a fragment it preserves position via the visible anchor (e.g. CFI restore after layout); fragments still scroll via settleSection.

**Consequences.** No resource reads or new blobs for in-place redisplay.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#display`

## Page-turn effects may prepare asynchronously

**Context.** A host decoration may need to prepare before movement.

**Decision.** pageTurnEffect may return {ready, cancel}; cancel must release ready.

**Consequences.** Hosts must resolve ready on cancel to avoid hangs.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#CreateNavigatorOptions.pageTurnEffect`

## End targets restore the last rendered box measured from origin

**Context.** Root client rect shifts with horizontal scroll in some browsers; column overflow may include an empty terminal column.

**Decision.** For position "end", scroll to page 0 first, then align to lastRenderedRange; fall back to the last spread only if none.

**Consequences.** Arrival at chapter end shows real content.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#positionMount`

## Programmatic arrival at an end does not trigger forward scroll

**Context.** A queued native scroll event after positioning could advance again.

**Decision.** #positionMount records mount.scrollTop after positioning so the scroll listener treats it as a restore.

**Consequences.** No double-advance.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#positionMount`

## Restore prefers saved section progression over CFI geometry

**Context.** Progression and CFI are saved together.

**Decision.** restoreProgression maps local progression to pageIndex = round(local*(pageCount-1)) and should be preferred when both are available.

**Consequences.** Restores are layout-stable.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#restoreProgression`

## Schedule host callbacks on the trusted host window

**Context.** WebKit/Safari may refuse to run rAF/callbacks scheduled in a sandboxed publication window.

**Decision.** Scroll coalescing, page-turn animation, and section layout callbacks use the container's ownerDocument.defaultView as scheduler, while listeners still observe the publication window.

**Consequences.** Callers embedding a document pass the host window.

**Code.** `packages/epub-successor/src/navigator/navigator.ts#scrollScheduler`

## Pagination never sets background

**Context.** Theme/preference CSS owns html+body paint.

**Decision.** Layout CSS sets geometry only.

**Consequences.** Themes are not overridden.

**Code.** `packages/epub-successor/src/navigator/paginated.ts`

## Two-page spreads pad to an even column count

**Context.** With an odd column count the final turn exceeds maxOffset; the browser clamps and the last spread re-shows the second-to-last column.

**Decision.** measurePaginatedLayout widens the body to a whole number of spreads; the trailing column stays blank.

**Consequences.** Last spread lands on a spread boundary.

**Code.** `packages/epub-successor/src/navigator/paginated.ts#measurePaginatedLayout`

## Widen single-page body to compensate for Chromium scrollWidth

**Context.** Chromium multicol scrollWidth stops at the last content edge, omitting the trailing half-gap of a single-page inset.

**Decision.** Count pages from the natural extent, then widen body to the last full stride.

**Consequences.** Terminal column not clamped early.

**Code.** `packages/epub-successor/src/navigator/paginated.ts#measurePaginatedLayout`

## Horizontal chrome lives on host; single-page margin becomes column gap

**Context.** Body side padding paints only at scrollLeft=0, offsetting later pages.

**Decision.** Paginated body has vertical padding (24px) only; DEFAULT_COLUMN_GAP 64 is the middle gutter of spreads. A single-page inline margin keeps the iframe full-width, narrows columns, and uses 2*margin as the inter-column gap so moving text paints through the margin while settled pages share the same inset. Scroll mode also uses vertical-only padding.

**Consequences.** All pages share one origin.

**Code.** `packages/epub-successor/src/navigator/paginated.ts#pageChromeInsets`

## Paginated restore uses floor of the range box

**Context.** Rounding the column index pushes restore one page forward when the caret is past mid-column; scrollIntoView and markers are imprecise.

**Decision.** restoreRange measures the range's live client box (first rect, not the parent block) in the current layout and jumps to column floor(x/stride).

**Consequences.** Restore is not off-by-one.

**Code.** `packages/epub-successor/src/navigator/paginated.ts#pageIndexForLogicalOffset`

## preferenceCss overrides built-in theme colors

**Context.** Host UI resolves theme colors.

**Decision.** Prefer app preferenceCss over THEME_COLORS so html/body match host; THEME_COLORS remains a base for the package demo.

**Consequences.** Two sources of colors.

**Code.** `packages/epub-successor/src/navigator/preferences.ts`

## Section layout anchoring rules

**Context.** After measuring pagination.

**Decision.** Element/fragment anchors align to the element; otherwise current scroll snaps to a spread boundary (live paging/resize).

**Consequences.** Resize keeps spread alignment.

**Code.** `packages/epub-successor/src/navigator/section-layout.ts`

## lastRenderedRange skips hidden nodes and trailing whitespace

**Context.** End targets should land on visible content.

**Decision.** lastRenderedRange excludes clipped/hidden nodes and trailing whitespace.

**Consequences.** Accurate end restore.

**Code.** `packages/epub-successor/src/navigator/visible-text.ts#lastRenderedRange`
